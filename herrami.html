Herramientas & Frameworks

Software, control de versiones, diseño UI/UX y entornos colaborativos recomendados para proyectos universitarios

Aquí encontrarás las herramientas más útiles para desarrollar, organizar y presentar tus proyectos académicos. Todas son gratuitas o tienen plan gratuito para estudiantes.

Control de versiones y repositorios

Esencial

Git + GitHub

Control de versiones, trabajo en equipo y portafolio profesional. Ideal para cualquier proyecto de ingeniería o desarrollo.

Ir a GitHub
Alternativa

GitLab

Similar a GitHub, con más herramientas de DevOps integradas. Muy usado en proyectos de software.

Ir a GitLab
Desktop

GitHub Desktop

Interfaz gráfica sencilla para usar Git sin necesidad de terminal. Perfecto si estás empezando.

Descargar

Diseño UI/UX y prototipos

Recomendado

Figma

Diseño de interfaces, prototipos interactivos y colaboración en tiempo real. Estándar de la industria.

Ir a Figma
Fácil

Canva

Diseño de presentaciones, afiches, infografías y reportes visuales. Muy intuitivo para cualquier carrera.

Ir a Canva
Prototipos

Penpot

Alternativa open source a Figma. Ideal si buscas una herramienta 100% gratuita y sin límites.

Ir a Penpot

Colaboración y productividad

Documentos

Google Drive + Docs

Edición colaborativa de documentos, hojas de cálculo y presentaciones en tiempo real.

Ir a Drive
Notas

Notion

Wiki del proyecto, bases de datos, tareas y documentación todo en un solo lugar.

Ir a Notion
Tareas

Trello / ClickUp

Gestión de tareas tipo Kanban. Perfecto para organizar el trabajo del equipo por sprints.

Ir a Trello
Comunicación

Discord / Slack

Canales de comunicación del equipo, reuniones y compartir archivos de forma ordenada.

Ir a Discord

Desarrollo y código

Editor

Visual Studio Code

El editor de código más popular. Ligero, con extensiones para casi cualquier lenguaje.

Descargar
Frontend

React / Vue / Angular

Frameworks modernos para desarrollo web. Ideal para proyectos de sistemas e informática.

Ver React
Backend

Node.js / Django / Spring

Opciones populares para el servidor según el lenguaje que uses (JavaScript, Python o Java).

Ver Node.js

Escritura y citas

Citas

Zotero

Gestor de referencias bibliográficas gratuito. Genera citas APA, IEEE y más automáticamente.

Descargar Zotero
Escritura

Overleaf (LaTeX)

Editor online de LaTeX. Perfecto para tesis técnicas, papers y documentos con muchas fórmulas.

Ir a Overleaf
Gramática

LanguageTool / Grammarly

Correctores de ortografía y estilo. LanguageTool tiene muy buen soporte para español.

Ir a LanguageTool

Consejo

No necesitas usar todas estas herramientas. Elige las que realmente te ayuden según el tipo de proyecto (desarrollo, investigación, diseño o trabajo en equipo).
